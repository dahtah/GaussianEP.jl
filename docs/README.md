# Documentation for GaussianEP.jl

The docs live in their **own Julia environment** (`docs/Project.toml` +
`docs/Manifest.toml`), completely separate from the package environment at
the repository root. The docs environment contains:

- `Documenter.jl` — builds the static site,
- `Literate.jl` — executes the notebooks,
- `GaussianEP` itself, added with `Pkg.develop(path = "..")` so the docs are
  always built against the working copy of the package.

The root `Project.toml` / `Manifest.toml` are never touched by the docs build.

## Building the docs

From the repository root:

```sh
julia --project=docs docs/make.jl
```

This renders `docs/src/*.md` (plus any executed notebooks) into `docs/build/`.
Open `docs/build/index.html` in a browser, or serve it locally:

```sh
cd docs/build && python3 -m http.server
# then visit http://localhost:8000
```

`docs/make.jl` runs `makedocs` with `doctest = false`, so code blocks in the
markdown pages are *not* executed during the build (the quick-start example on
the landing page is verified separately against the package test suite).

## Layout

```
docs/
├── Project.toml / Manifest.toml   # docs-only environment (Documenter, Literate, GaussianEP dev'd)
├── make.jl                        # build script (Documenter + Literate)
├── README.md                      # this file
├── notebooks/                     # Literate source scripts (*.jl), executed at build time
│   └── gp_classification.jl       # e.g. GP classification example
└── src/
    ├── index.md                   # landing page + quick start
    ├── api.md                     # @docs reference
    ├── notebooks.md               # notebook index (links to src/notebooks/*.md)
    └── notebooks/                 # generated by Literate from docs/notebooks/*.jl
```

## Adding a notebook

1. Write a Literate script `docs/notebooks/my_example.jl` using Literate's
   markdown-ish format (`# %%` starts a new cell, `#` lines are markdown,
   `#+` lines are Julia code with captured output).
2. Re-run the build: `julia --project=docs docs/make.jl`.
   `make.jl` executes every `docs/notebooks/*.jl` and writes the rendered
   page to `docs/src/notebooks/my_example.md`, and adds it to the site
   navigation automatically.
3. Link to it from `docs/src/notebooks.md`, e.g.
   `[My example](notebooks/my_example.md)`.

The notebook runs in the docs environment, so `using GaussianEP` (and any
other package you add to `docs/Project.toml`) works out of the box. If no
notebooks exist yet, the build still succeeds — the notebook step is guarded
with `isdir`.
